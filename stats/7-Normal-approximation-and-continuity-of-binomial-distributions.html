📊 이항분포의 정규근사와 연속성 수정

Binomial to Normal Approximation & Continuity Correction

🎯핵심 질문

이항분포 B(n, p)를 정규분포로 근사화했다면,

P(X = k)를 P(k - 0.5 ≤ X ≤ k + 0.5)로 계산할 수 있는가?

이것이 바로 연속성 수정(Continuity Correction)입니다.

🤔왜 연속성 수정이 필요한가?

🎲이항분포 B(n,p)

타입: 이산 확률분포

특징:

  • 정수값만 가능 (0, 1, 2, 3, ...)
  • P(X = k)가 의미 있음
  • 한 점에서 확률 > 0
P(X = 5) = 실제 값
📈정규분포 N(μ, σ²)

타입: 연속 확률분포

특징:

  • 모든 실수값 가능
  • P(X = k) = 0 (한 점의 확률)
  • 구간 확률만 의미 있음
P(X = 5) = 0
⚠️핵심 문제

이산분포에서는 P(X = k)가 의미 있지만, 연속분포에서는 한 점에서의 확률이 0입니다!

따라서 이산값 k를 연속분포에서 표현하려면 구간으로 변환해야 합니다.

🔧연속성 수정 방법

이산값 k를 연속분포에서 표현할 때, k는 실제로 [k - 0.5, k + 0.5] 구간을 대표한다고 봅니다.

시각적 이해

k-2
k-1
k
[k-0.5, k+0.5]
k+1
k+2

이산값 k는 연속분포에서 k-0.5부터 k+0.5까지의 구간으로 대응됩니다.
이렇게 하면 이산분포와 연속분포 사이의 간격을 메울 수 있습니다.

P(X = k) ≈ P(k - 0.5 ≤ X ≤ k + 0.5)

📐다양한 경우의 연속성 수정

이항분포를 정규분포로 근사할 때, 다양한 확률 계산에 연속성 수정을 적용하는 방법:

P(X = k)
P(k-0.5 ≤ X ≤ k+0.5)
P(X ≤ k)
P(X ≤ k+0.5)
P(X < k)
P(X ≤ k-0.5)
P(X ≥ k)
P(X ≥ k-0.5)
P(X > k)
P(X ≥ k+0.5)
P(a ≤ X ≤ b)
P(a-0.5 ≤ X ≤ b+0.5)
💡기억 팁
  • "이상(≥)" 또는 "초과(>)": 아래쪽 경계에서 0.5를 뺍니다
  • "이하(≤)" 또는 "미만(<)": 위쪽 경계에서 0.5를 더합니다
  • "정확히 같음(=)": 양쪽 모두 적용 (±0.5)

🧮구체적인 예제

📝예제: 동전 던지기

공정한 동전을 100번 던질 때, 앞면이 정확히 52번 나올 확률을 정규근사로 구하세요.

1️⃣Step 1: 이항분포 설정

X ~ B(n=100, p=0.5)

2️⃣Step 2: 정규분포 파라미터 계산
μ = np = 100 × 0.5 = 50
σ² = np(1-p) = 100 × 0.5 × 0.5 = 25
σ = √25 = 5

따라서 X ~ N(μ=50, σ²=25) 또는 N(50, 5²)

3️⃣Step 3: 연속성 수정 적용

P(X = 52)를 구하려면:

P(X = 52) ≈ P(51.5 ≤ X ≤ 52.5)
4️⃣Step 4: 표준화 (Z-score 계산)
Z₁ = (51.5 - 50) / 5 = 1.5 / 5 = 0.3
Z₂ = (52.5 - 50) / 5 = 2.5 / 5 = 0.5
5️⃣Step 5: 표준정규분포표 이용
P(0.3 ≤ Z ≤ 0.5) = Φ(0.5) - Φ(0.3)
= 0.6915 - 0.6179
= 0.0736

답: 약 7.36%

100번의 동전 던지기에서 정확히 52번 앞면이 나올 확률은 약 7.36%입니다.

⚡연속성 수정의 중요성

만약 연속성 수정 없이 P(X = 52)를 그냥 P(X = 52)로 계산하면 확률이 0이 되어버립니다!
연속성 수정을 사용하면 근사의 정확도가 크게 향상됩니다.

✅정규근사 사용 조건

이항분포를 정규분포로 근사할 때는 다음 조건을 만족해야 합니다:

📊일반적인 경험 규칙
✓ np ≥ 5
✓ n(1-p) ≥ 5

두 조건을 모두 만족하면 정규근사가 비교적 정확합니다.

🔍조건 확인 예시

상황 1: n=100, p=0.5

np = 100 × 0.5 = 50 ≥ 5 ✅
n(1-p) = 100 × 0.5 = 50 ≥ 5 ✅

→ 정규근사 사용 가능!

상황 2: n=20, p=0.1

np = 20 × 0.1 = 2 < 5 ❌
n(1-p) = 20 × 0.9 = 18 ≥ 5 ✅

→ 정규근사 부적합! 이항분포 직접 사용
