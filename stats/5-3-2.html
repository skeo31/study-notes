χ²-분포의 재생성(Reproductive) 성질

재생성 성질이란?

χ²-분포를 따르는 독립인 확률변수들을 더하면, 그 합도 여전히 χ²-분포를 따른다. 단, 자유도는 각각의 자유도를 모두 더한 값이 된다.

\[ X_i \sim \chi^2(n_i), \quad X_1,X_2,\ldots,X_k \text{ 서로 독립} \] \[ \Downarrow \] \[ Y = \sum_{i=1}^{k} X_i \;\sim\; \chi^2\!\!\left(\sum_{i=1}^{k} n_i\right) \]
💡 한 줄 직관
χ²-분포끼리 더하면 "분포의 종류는 유지"되고, "자유도만 합산"된다. 마치 같은 언어를 쓰는 사람끼리는 대화가 통하듯이, χ² 변수끼리는 더해도 χ²로 남는다.

재생성 성질 — 직관: 자유도는 "쌓인다"

자유도를 블록처럼 생각하자

자유도를 "독립적으로 움직일 수 있는 칸의 수"라고 생각하면, 독립인 χ² 변수를 합치는 것은 블록을 쌓는 것과 같다.

\(X_1\)
자유도
\(n_1 = 3\)
+
\(X_2\)
자유도
\(n_2 = 2\)
+
\(X_3\)
자유도
\(n_3 = 4\)
=
\(Y = X_1\!+\!X_2\!+\!X_3\)
← \(n_1=3\)
← \(n_2=2\)
← \(n_3=4\)
자유도
\(n_1+n_2+n_3 = 9\)
\(Y \sim \chi^2(3+2+4) = \chi^2(9)\)
⚠ 반드시 독립이어야 한다
블록을 "그냥 쌓는" 것이 가능하려면 각 변수가 서로 독립이어야 한다. 독립이 아니라면 합의 분포는 χ²-분포가 아닐 수 있다.

왜 성립하는가? — 증명 아이디어

χ²-분포의 출발점을 기억하자

χ²-분포의 핵심 성질 (1)을 먼저 떠올린다:

\[Z \sim \mathrm{N}(0,1) \;\Longrightarrow\; Z^2 \sim \chi^2(1)\]
표준정규변수 하나를 제곱하면 → 자유도 1인 χ²
자유도 n인 χ² = 표준정규변수 n개의 제곱합

서로 독립인 \(Z_1, Z_2, \ldots, Z_n \sim \mathrm{N}(0,1)\)이면:

\[ X = Z_1^2 + Z_2^2 + \cdots + Z_n^2 = \sum_{i=1}^n Z_i^2 \;\sim\; \chi^2(n) \]
💡 재생성 성질의 직관적 증명

이제 \(X_1 \sim \chi^2(n_1)\), \(X_2 \sim \chi^2(n_2)\)이고 서로 독립이라 하자.

\(X_1\)은 독립인 표준정규변수 \(n_1\)개의 제곱합, \(X_2\)는 독립인 표준정규변수 \(n_2\)개의 제곱합이다.

\(X_1\)과 \(X_2\)가 서로 독립이므로, 이 두 그룹의 표준정규변수들은 모두 서로 독립이다. 따라서 합 \(Y = X_1 + X_2\)는 독립인 표준정규변수 \((n_1+n_2)\)개의 제곱합 → \(\chi^2(n_1+n_2)\)

적률생성함수(MGF)로도 확인 가능:
\(M_{X_i}(t) = (1-2t)^{-n_i/2}\) 이고, 독립이면 MGF를 곱하므로: \[ M_Y(t) = M_{X_1}(t)\cdot M_{X_2}(t) = (1-2t)^{-n_1/2}\cdot(1-2t)^{-n_2/2} = (1-2t)^{-(n_1+n_2)/2} \] → 자유도 \((n_1+n_2)\)인 χ²-분포의 MGF와 일치!

재생성 성질 — 활용 & 요약

이 성질이 어디에 쓰이는가?
📐 활용 1 — χ²-분포 성질 (3)(ii) 도출에 직접 사용

표본분산의 분포를 유도할 때:

\[ \underbrace{\sum_{i=1}^n \frac{(X_i-\mu)^2}{\sigma^2}}_{\chi^2(n)} = \underbrace{\frac{(n-1)S^2}{\sigma^2}}_{\text{?}} + \underbrace{\left(\frac{\overline{X}-\mu}{\sigma/\sqrt{n}}\right)^2}_{\chi^2(1)} \]

좌변 \(\chi^2(n)\)이 두 독립인 χ² 변수의 합이므로, 재생성 성질을 거꾸로 적용하면: \(\dfrac{(n-1)S^2}{\sigma^2} \sim \chi^2(n-1)\)이 된다.

전자공학 응용 — 여러 센서 노이즈의 합산 분석
상황: IoT 시스템에서 센서 A, B, C 세 채널의 노이즈 에너지를 각각 \(\chi^2(n_1)\), \(\chi^2(n_2)\), \(\chi^2(n_3)\)으로 모델링한다. 각 채널이 서로 독립이면, 총 노이즈 에너지의 분포는:
\[ Y_\text{total} = Y_A + Y_B + Y_C \;\sim\; \chi^2(n_1+n_2+n_3) \]
실용적 의미: 각 채널을 따로 분석하지 않고, 합산된 χ²-분포 하나로 전체 시스템의 노이즈 허용 임계값을 한 번에 계산할 수 있다.
