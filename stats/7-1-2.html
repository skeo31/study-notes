Q 1

기각역 방법과 p-value 방법은
왜 교과서에서 따로 설명하는가?

두 방법의 절차 요약

① 기각역 방법

  • 유의수준 \(\alpha\) 를 미리 설정
  • 표준 정규 분포에서 기각역 결정
  • 검정통계량 \(Z_{obs}\) 계산
  • \(|Z_{obs}| > z_{\alpha/2}\) 이면 귀무가설 기각

② p-value 방법

  • \(Z_{obs}\) 로부터 p-value 계산
  • \(p\text{-value} = P(|Z| > |Z_{obs}|)\)
  • \(p < \alpha\) 이면 귀무가설 기각
  • α는 비교 대상으로만 사용

수학적 동치 증명

두 방법이 항상 같은 결론을 내린다는 것은 다음과 같이 엄밀하게 보일 수 있습니다.

\[ p\text{-value} < \alpha \;\iff\; P\!\left(|Z| > |Z_{obs}|\right) < \alpha \;\iff\; |Z_{obs}| > z_{\alpha/2} \]
핵심 결론
세 부등식은 모두 동치(⟺)입니다. 따라서 두 방법은 수학적으로 완전히 같은 판단을 내립니다.

그럼에도 따로 가르치는 이유

관점 기각역 방법 p-value 방법
역사적 기원 Neyman–Pearson (1930년대)
의사결정 이론		 R. A. Fisher
증거의 강도 측정
결론의 형태 기각 / 불기각 (이진) 연속 확률값 (0 ~ 1)
α 역할 경계선을 미리 확정 사후 비교 기준
적합한 맥락 공정 합·불합 판정 등
사전 결정 규칙 필요 시		 논문·연구 보고 등
독자가 직접 판단 시
교육적 역할 분포 구조·임계값 직관 학습 증거 강도 개념 심화

두 방법은 계산상 동치이지만, 강조하는 개념적 프레임이 다릅니다. 기각역은 "어디서 자를 것인가(경계)"를, p-value는 "관찰값이 얼마나 극단적인가(증거의 강도)"를 표현합니다. 수식은 같아도 통계 철학이 달라 교과서는 두 관점을 모두 가르칩니다.

Q 2

p-value는 유의수준 α로부터
얼마나 떨어진 값인가?

p-value는 확률값(0과 1 사이)이므로, 유의수준 α와의 상대적 위치를 통해 기각의 이진 결론에 더해 증거의 강도라는 추가 정보를 줍니다.

같은 기각이라도 강도는 다르다

── α = 0.05 로 설정 ──────────────────────────
p = 0.049 → 기각 // α = 0.05에 아슬아슬하게 걸침 → 약한 증거
p = 0.001 → 기각 // α = 0.05보다 훨씬 작음 → 강한 증거
p = 0.300 → 불기각 // α = 0.05보다 훨씬 큼 → 귀무가설과 잘 일치
해석 원칙
p-value가 작을수록 귀무가설 하에서 이런 극단적인 데이터가 나올 확률이 낮다는 뜻이며, 귀무가설에 반하는 증거가 더 강합니다.

단, "거리"는 선형이 아니다

α와의 단순 수치 차이(α − p)는 증거 강도를 왜곡할 수 있습니다.

\[ \underbrace{p = 0.04 \;\text{vs}\; p = 0.01}_{\text{차이 } = 0.03} \quad\text{vs}\quad \underbrace{p = 0.01 \;\text{vs}\; p = 0.001}_{\text{차이 } = 0.009} \]
주의
숫자 차이(0.03 vs 0.009)만 보면 전자가 더 큰 차이처럼 보이지만,
증거 강도의 차이는 오히려 후자(0.01 → 0.001)가 훨씬 큽니다.
따라서 배율 또는 로그 척도로 비교하는 것이 더 올바릅니다.

요약

결론
p-value는 α와의 단순 차이가 아니라, α 대비 몇 배 작은가 또는 로그 척도에서 얼마나 멀리 떨어져 있는가로 읽을 때 증거 강도를 제대로 파악할 수 있습니다.
Q 3

두 p-value의 기각 강도 비교
단순 차이 vs 배율 vs 로그 척도

예시 설정
\(\alpha = 0.05\),  \(p_1 = 0.04\),  \(p_2 = 0.001\)
두 값 모두 \(p < \alpha\) 이므로 귀무가설 기각.

방법 1 — 단순 차이 (α 기준)

\[ \alpha - p_1 = 0.05 - 0.04 = 0.01 \] \[ \alpha - p_2 = 0.05 - 0.001 = 0.049 \] \[ \frac{0.049}{0.01} = 4.9 \;\text{배} \quad \Rightarrow \quad p_2 \text{ 가 약 5배 더 강한 증거처럼 보임} \]
문제점
α = 0.05라는 자의적 기준에 의존하므로, α를 바꾸면 결과도 달라집니다. 두 관찰값 자체의 본질적 차이를 반영하지 못합니다.

방법 2 — 배율 비교 (권장)

\[ \frac{p_1}{p_2} = \frac{0.04}{0.001} = \mathbf{40\text{ 배}} \]
해석
\(p_2\) 는 \(p_1\) 보다 40배 더 극단적인 관찰값에 해당합니다.
이 배율은 α와 무관하게 두 관찰값 자체의 상대적 극단성을 나타냅니다.

방법 3 — 로그 척도 비교

\[ \ln(p_1) = \ln(0.04) \approx -3.22 \] \[ \ln(p_2) = \ln(0.001) \approx -6.91 \] \[ \Delta = -6.91 - (-3.22) = -3.69 \]

로그 척도에서 \(p_2\)는 \(p_1\)보다 3.69 단위 더 극단적입니다. 참고로 \(\ln(40) \approx 3.69\) 이므로, 배율 40배와 정확히 같은 정보입니다.

\[ \ln\!\left(\frac{p_1}{p_2}\right) = \ln(p_1) - \ln(p_2) = \ln(40) \approx 3.69 \]

세 방법 종합 비교

비교 방법 계산 결과 α 의존성 해석
단순 차이 (α 기준) 4.9배 있음 ⚠️ α를 바꾸면 달라짐
배율 (p₁ / p₂) 40배 없음 ✅ 관찰값 자체의 극단성
로그 차이 3.69 단위 없음 ✅ 배율과 동일 정보 (지수 척도)

배율 \(p_1 / p_2 = 40\) 은 유의수준 α와 무관하게 두 관찰 결과가 귀무가설과 얼마나 다른지를 나타냅니다. 단순 차이(4.9배)는 α라는 임의 기준에 묶여 있어 본질적 비교에 부적합합니다. 단, p-value만으로는 실질적 중요성을 알 수 없으므로, 효과 크기(effect size)와 함께 해석하는 것이 현대 통계학의 권고입니다.
