Step 1
Step 1 이항분포를 베르누이 합으로 표현
이항분포 → 베르누이 합
이항분포의 구조를 분해해서 CLT를 적용할 수 있는 형태로 만든다
핵심 아이디어: X ~ B(n, p) 는 "n번의 독립 시행에서 성공 횟수"이다. 각 시행의 결과를 Xᵢ로 나타내면, X는 그 합이다.
정의
베르누이 확률변수 Xᵢ
i번째 시행의 결과:
이항분포의 분해
X₁, X₂, …, Xₙ 은 독립이고 동일 분포 (i.i.d.)
각 Xᵢ의 평균과 분산
기댓값
E[Xᵢ] = 1·p + 0·(1−p) = p
분산
Var(Xᵢ) = E[Xᵢ²] − (E[Xᵢ])² = p − p² = p(1−p)
이 분해가 중요한 이유:
X를 i.i.d. 확률변수들의 합으로 표현했으므로, 이제 CLT를 직접 적용할 수 있는 구조가 되었다.
Step 2-1
Step 2-1 표본합의 기댓값
표본합의 기댓값
기댓값의 선형성을 이용한다
표본합 정의
기댓값 유도
사용 성질: 기댓값의 선형성
E[aX + bY] = a·E[X] + b·E[Y]  — 독립 여부와 무관하게 항상 성립
↓   기댓값의 선형성 적용
↓   각 E[Xᵢ] = p 대입
↓   정리
해석: 표본합의 기댓값은 np이다. n번 시행에서 기대되는 성공 횟수가 np임을 직접 확인할 수 있다.
Step 2-2
Step 2-2 표본합의 분산
표본합의 분산
독립성을 이용해 분산을 분해한다
사용 성질 1: 상수 배의 분산
Var(aX) = a²·Var(X)  — 상수는 분산 앞에서 제곱으로 나온다
사용 성질 2: 독립 확률변수 합의 분산
X₁, …, Xₙ이 독립이면   Var(X₁ + ⋯ + Xₙ) = Var(X₁) + ⋯ + Var(Xₙ)
분산 유도
↓   Var(aX) = a²Var(X) 적용 → 1/n이 1/n²으로
↓   독립이므로 분산 분해
↓   각 Var(Xᵢ) = p(1−p) 대입
↓   정리
핵심 관찰: 표본합의 분산은 n에 비례하여 n배 증가한다. 이는 독립 확률변수 합의 분산이 각 분산의 합과 같다는 성질에서 직접 나온다.
Step 2-3
Step 2-3 왜 정규분포에 수렴하는가?
왜 정규분포에 수렴하는가?
평균·분산을 구한 것만으로는 부족하다 — 분포의 모양이 정규분포가 되는 이유
주의: 지금까지 E[Sₙ] = np, Var(Sₙ) = np(1−p) 을 구했지만, 이것만으로는 분포의 모양이 정규분포라는 뜻이 아니다. 평균과 분산이 같아도 분포의 모양은 다를 수 있다.
표준화된 합으로 재표현
표준화된 표본평균 Zₙ을 개별 항으로 분해하면:
↓   각 항을 표준화된 단위 Yᵢ로 묶으면
Yᵢ의 성질:  
Yᵢ는 평균 0, 분산 1인 표준화된 베르누이 확률변수
n이 커지면 무슨 일이 벌어지나
n 증가 시 변화 이유 관련 정리
분포의 중심은 np로 고정 E[Sₙ] = np 는 n에 비례 기댓값 선형성
분포의 퍼짐은 √n 비율로 증가 Var(Sₙ) = np(1−p) → 표준편차 √(np(1−p)) 대수의 법칙 (LLN)
분포의 모양은 정규분포로 MGF 수렴 (Step 4에서 증명) 중심극한정리 (CLT)
결론: Zₙ = ΣYᵢ / √n 형태는 n → ∞ 일 때 MGF를 통해 N(0,1)로 수렴함을 증명할 수 있다. → Step 4
Step 3
Step 3 표준화
표준화
표본합을 평균 0, 분산 1인 형태로 변환한다
표준화 공식 적용
Step 2에서 구한 E[Sₙ] = np, Var(Sₙ) = np(1−p) 을 대입한다.
↓   Sₙ = X₁ + ⋯ + Xₙ 대입, 분모 정리
↓   드무아브르-라플라스 표준화 형태
이것이 드무아브르-라플라스 정리의 형태다.
X ~ B(n, p) 를 직접 표준화한 것과 동일한 결과가 나온다.
드무아브르-라플라스와의 연결
CLT 경로 (이번 유도)
X를 베르누이 합으로 분해
→ 표본합 Sₙ 구성
→ 표준화
드무아브르-라플라스 (직접)
X ~ B(n, p) 에서
평균 np, 분산 np(1−p)
→ 직접 표준화
두 식은 동일하다. CLT 프레임(표본합)으로 유도해도 드무아브르-라플라스 정리와 정확히 같은 표준화 식이 나온다.
Step 4
Step 4 MGF 수렴 증명
MGF 수렴 증명
적률생성함수(MGF)가 N(0,1)의 MGF로 수렴함을 보인다
핵심 도구: MGF 수렴 정리 (Continuity Theorem)
Zₙ의 MGF가 모든 t에서 Z의 MGF로 수렴하면, Zₙ →d Z
4-1. 표준화된 베르누이 Yᵢ의 MGF
4-2. Zₙ의 MGF
전제:   Z_n = (Y₁ + Y₂ + ⋯ + Yₙ) / √n  이고, Yᵢ는 서로 독립이며 동일한 분포를 따른다 (i.i.d.)
① MGF 정의 적용 — 지수의 합을 곱으로 분리
↓   ea+b = ea·eb 적용
② 독립성 → 기댓값의 곱으로 분해
Yᵢ들이 독립이면   E[f(Y₁)·f(Y₂)⋯] = E[f(Y₁)]·E[f(Y₂)]⋯  가 성립한다.
③ 동일 분포(i.i.d.) → n제곱으로 정리
모든 Yᵢ가 동일한 분포이므로 각 기댓값은 모두 같다.   MY(s) = E[esYᵢ] 정의에서 s = t/√n 으로 치환하면:
핵심 논리 구조
지수의 합 → 지수의 곱   ea+b=eaeb
기댓값의 곱 분해  →  독립성
n제곱으로 묶음  →  동일 분포
MGF 기호로 치환  →  MY(s) 정의
s = t/√n 치환의 의미
Zₙ에 t를 곱하면 각 Yᵢ에는
t/√n 이 곱해지는 구조.
n → ∞ 이면 s → 0 이므로
다음 단계 테일러 전개가 가능해진다.
4-3. 로그를 취한 뒤 테일러 전개
s = t/√n 으로 놓으면 n → ∞ 일 때 s → 0 이므로, MY(s)를 s = 0 근방에서 테일러 전개:
여기서 MGF의 도함수와 기댓값 사이의 관계를 사용합니다:
0차 도함수
1차 도함수
2차 도함수
(E[Yᵢ] = 0, E[Yᵢ²] = Var(Yᵢ) = 1 이므로)
4-4. 극한 계산
↓   ln(1 + u) ≈ u (u → 0)
↓   n → ∞
e^(t²/2) 는 N(0,1)의 MGF다.
MGF 수렴 정리에 의해 Zₙ →d N(0, 1) 이 성립한다.   □
부록 — N(0,1)의 MGF = e^(t²/2) 유도
목표:   Z ~ N(0,1) 일 때   M(t) = E[etZ] = et²/2   임을 직접 계산으로 확인한다.
① 적분 형태로 전개
② 완전제곱식 (completing the square)
지수 안의 식을 z에 대해 정리한다.
↓   t²을 더하고 빼서 완전제곱 완성
③ e^(t²/2) 를 적분 밖으로 분리
et²/2는 z와 무관한 상수이므로 적분 밖으로 꺼낼 수 있다.
④ 치환 u = z − t  →  가우스 적분 적용
u = z − t 로 놓으면 du = dz, 적분 범위는 그대로 (−∞, ∞).
↓   가우스 적분   ∫e^(−u²/2)du = √(2π)   적용
↓   √(2π) 상쇄
전체 흐름 요약
① 정의: E[etZ] = ∫ etz · (1/√2π)e−z²/2 dz
② 완전제곱식으로 지수 정리
③ et²/2 를 밖으로 분리
④ u = z−t 치환
⑤ 가우스 적분 ∫e−u²/2du = √2π 로 상쇄
가우스 적분이 성립하는 이유
N(0,1) 확률밀도함수의 전체 면적은 1.

즉   ∫ (1/√2π) e−u²/2 du = 1

양변에 √2π를 곱하면
∫ e−u²/2 du = √2π
결론
Summary 전체 유도 요약
전체 유도 요약
단계 핵심 작업 사용 도구 결과
Step 1 X를 베르누이 합으로 분해 i.i.d. 구조 확인 X = ΣXᵢ, E[Xᵢ]=p, Var(Xᵢ)=p(1−p)
Step 2-1 표본합의 기댓값 기댓값 선형성 E[Sₙ] = np
Step 2-2 표본합의 분산 독립성 + Var(X+Y)=Var(X)+Var(Y) Var(Sₙ) = np(1−p)
Step 2-3 왜 정규분포 모양? Zₙ = ΣYᵢ/√n 재표현 MGF 증명으로 연결
Step 3 표준화 Z = (Sₙ−np) / √(np(1−p)) 드무아브르-라플라스 형태
Step 4 MGF 수렴 증명 테일러 전개 + MGF 수렴 정리 MGF → e^(t²/2) = N(0,1)의 MGF
드무아브르-라플라스와의 관계:
이 유도는 이항분포에 CLT를 적용한 것이며, 드무아브르-라플라스 정리를 CLT 프레임에서 재증명한 것이다.
일반화:
Step 1에서 베르누이 대신 임의의 i.i.d. 분포(유한 분산)를 넣어도 Step 4의 MGF 수렴 논증은 동일하게 성립한다 → 일반 CLT.
