신뢰구간 공식 유도
복습: 5.2 표본평균의 분포
📐
기댓값 (불편성)
$$\text{E}(\bar{X}) = \mu$$
표본평균의 기댓값은 모평균과 같다. 이 때문에 표본평균은 모평균의 불편추정량이다.
📉
분산 (표준오차)
$$\text{Var}(\bar{X}) = \dfrac{\sigma^2}{n}$$
표본 크기 n이 클수록 분산이 감소 → 추정 정밀도 증가. 표준편차를 표준오차(SE)라 한다.
🔔
중심극한정리
$$\bar{X} \sim \text{N}\!\left(\mu, \dfrac{\sigma^2}{n}\right)$$
모집단이 정규분포이면 n에 무관하게, 아니더라도 n→∞이면 근사적으로 정규분포를 따른다.
📊
Z-통계량 표준화
$$Z = \dfrac{\bar{X} - \mu}{\sigma/\sqrt{n}} \sim \text{N}(0,1)$$
이 Z-통계량이 신뢰구간 유도의 핵심 출발점이다.
복습: 5.3 t-분포와 χ²-분포
📈
t-분포 (소표본 핵심)

Z~N(0,1), V~χ²(n)이 독립일 때:

$$T = \dfrac{Z}{\sqrt{V/n}} \sim t(n)$$

정규분포보다 꼬리가 두껍다. n→∞이면 N(0,1)에 수렴.

🔑
정규모집단 + 모분산 모름

❓ 정규모집단이란?

모집단(전체 데이터)의 분포가 정규분포(종 모양 곡선)를 따른다는 가정이다.
예: 사람 키·몸무게, 공장 제품 치수 등은 현실에서 대체로 정규분포를 따른다.
이 가정이 있어야 소표본(n < 30)에서도 T 통계량이 t-분포를 따른다는 것이 수학적으로 보장된다. n ≥ 30이면 중심극한정리에 의해 이 가정 없이도 근사적으로 성립한다.

σ 대신 표본표준편차 S를 쓰면:

$$T = \dfrac{\bar{X}-\mu}{S/\sqrt{n}} \sim t(n-1)$$

자유도 (n−1)인 t-분포를 따른다. 소표본 신뢰구간에 사용.

t-분포는 정규분포보다 꼬리(주황 음영)가 높이 올라와 있다 — 극단값이 나올 확률이 더 크다는 뜻.
대신 중앙 봉우리는 정규분포보다 낮다. 자유도가 커질수록 t-분포는 N(0,1)에 가까워진다.
①
모평균의 점추정

모집단에서 표본을 추출하여 모수(parameter)를 하나의 값으로 추정하는 것을 점추정(point estimation)이라 한다.

$$\hat{\mu} = \bar{X}$$
모평균 점추정의 요약
🎯
(1) 점추정량
모평균 μ의 점추정량은 표본평균 X̄이다.
📏
(2) 표준오차 SE
$$\text{SE}(\bar{X}) = \dfrac{\sigma}{\sqrt{n}}$$
표준오차(standard error)란 추정량 \(\bar{X}\)의 표준편차이다.

❓ 표본표준편차 S와 다른가?
• 표본표준편차 S: 표본 내 데이터들이 표본평균 주위에 얼마나 퍼져 있는지 (= 데이터 자체의 산포)
• 표준오차 \(\text{SE} = \sigma/\sqrt{n}\): 표본평균 \(\bar{X}\)가 모평균 μ 주위에 얼마나 퍼져 있는지 (= 추정값의 불확실성)

SE는 S를 √n으로 나눈 것 → n이 클수록 SE가 작아져 추정이 정밀해진다.
↔️
(3) 오차한계
$$z_{\alpha/2}\dfrac{\sigma}{\sqrt{n}}$$
오차한계(limit of error)란 점추정값(X̄)이 참값(μ)과 얼마나 차이날 수 있는지의 최대 허용 범위이다.

즉, \[|\bar{X} - \mu| \leq z_{\alpha/2}\dfrac{\sigma}{\sqrt{n}} \quad\left(\Longleftrightarrow\; \left|\dfrac{\bar{X}-\mu}{\sigma/\sqrt{n}}\right| \leq z_{\alpha/2}\right)\] 가 100(1−α)% 확률로 성립한다는 의미다. 우변의 괄호 안 식에서 좌변 \(\dfrac{\bar{X}-\mu}{\sigma/\sqrt{n}} = Z \sim N(0,1)\)이므로, 이 부등식은 표준화 Z의 절댓값이 임계값 \(z_{\alpha/2}\) 이내임을 뜻한다.

예) 95% 오차한계 = 3.72 이면, "추정값이 참값과 3.72 이상 차이날 확률은 5% 이하"라는 뜻.
⚠️ 점추정의 한계 — 그리고 구간추정이 필요한 이유

점추정은 단 하나의 값(예: \(\bar{X} = 35.6\))을 제시한다. 그런데 그 값이 얼마나 믿을 만한지, 얼마나 오차가 있을 수 있는지는 알 수 없다.

🤔 "\(\bar{X} = 35.6\)이라고 했는데, 진짜 μ가 35.6인지, 아니면 30일 수도 있고 40일 수도 있는 건지 어떻게 알지?"

구간추정(interval estimation)은 이 물음에 답한다. 하나의 점(35.6)이 아니라 "35.6 ± 3.72, 즉 (31.88, 39.32) 구간 안에 모평균이 있다"는 식으로, 불확실성의 크기를 구간의 폭으로 표현한다.

구간이 좁을수록 → 추정이 정밀함 / 구간이 넓을수록 → 불확실성이 큼.
신뢰도(예: 95%)는 이 구간이 얼마나 믿을 만한지를 확률로 나타낸 것이다.

②
구간추정 — 모분산 σ² 아는 경우
📌 5.2와의 연결

5.2에서 증명한 \(\text{E}(\bar{X}) = \mu,\ \text{Var}(\bar{X}) = \sigma^2/n\)으로부터 \(\bar{X}\)를 표준화하면 Z ~ N(0,1)이 된다. 이것이 신뢰구간 유도의 출발점이다.

신뢰구간 유도
1
표준정규분포의 성질로부터 임의의 양수 α (0 < α < 1)에 대해:
$$\text{P}\!\left(-z_{\alpha/2} < Z < z_{\alpha/2}\right) = 1 - \alpha$$
여기서 z₀.₀₅ = 1.645, z₀.₀₂₅ = 1.96, z₀.₀₀₅ = 2.58
2
Z-통계량 \(Z = \dfrac{\bar{X}-\mu}{\sigma/\sqrt{n}}\)을 대입하면:
$$\text{P}\!\left(\left|\dfrac{\bar{X}-\mu}{\sigma/\sqrt{n}}\right| < z_{\alpha/2}\right) = 1-\alpha$$
3
동치 변환: \(|\bar{X} - \mu| < z_{\alpha/2}\dfrac{\sigma}{\sqrt{n}}\)
4
μ에 대해 풀면 100(1−α)% 신뢰구간:
$$\left(\bar{X} - z_{\alpha/2}\dfrac{\sigma}{\sqrt{n}},\quad \bar{X} + z_{\alpha/2}\dfrac{\sigma}{\sqrt{n}}\right)$$
즉, 추정값 ± 100(1−α)% 오차한계

정확한 해석

모집단으로부터 크기가 n인 표본의 임의추출을 반복하여 신뢰구간을 만들 때, 이들 중 약 95%는 모평균 μ를 포함한다는 의미이다.

즉, 표본평균 \(\bar{X}\)로 추정한 \(\bar{X} - 1.96\dfrac{\sigma}{\sqrt{n}}\) 와 \(\bar{X} + 1.96\dfrac{\sigma}{\sqrt{n}}\) 사이에 모평균 μ가 포함될 것이라는 신뢰 정도가 95%라는 의미이다.

각 가로 선분이 하나의 신뢰구간. 대부분 μ(점선)를 포함하지만, 일부는 포함하지 않는다.
④
모분산 모름 — 대표본 (n ≥ 30)
📌 중심극한정리 연결 (5.2)

n ≥ 30이면 중심극한정리에 의해 모집단 분포에 상관없이 \(\bar{X}\)는 근사적으로 정규분포를 따른다. 또한 σ가 알려지지 않아도 표본표준편차 S로 대체할 수 있다.

모분산 모름 — 소표본 (n < 30)
📌 5.3 t-분포 연결

소표본(n < 30)에서는 σ를 S로 교체할 때 Z-분포를 사용할 수 없다. 5.3에서 배운 t-분포를 사용해야 한다. T통계량은 자유도 (n−1)인 t-분포를 따른다.

소표본 T-통계량과 구간추정

모분산 σ²를 모를 때, n이 소표본(n < 30)이면 Z-통계량 대신 T-통계량을 사용한다:

$$T = \dfrac{\bar{X} - \mu}{S/\sqrt{n}} \sim t(n-1)$$

임의의 양수 α에 대해:

$$\text{P}\!\left(-t_{\alpha/2}(n-1) < T < t_{\alpha/2}(n-1)\right) = 1 - \alpha$$

μ에 대해 풀면 소표본 100(1−α)% 신뢰구간:

$$\left(\bar{X} - t_{\alpha/2}(n-1)\dfrac{S}{\sqrt{n}},\quad \bar{X} + t_{\alpha/2}(n-1)\dfrac{S}{\sqrt{n}}\right)$$
📌 주의: t 분포표에서 자유도 (n−1)행, α/2 열의 값을 찾아 사용한다. t값은 항상 z값보다 크다 (꼬리가 두꺼운 분포이므로).

예제 6-5 점추정, 표준오차, 95% 오차한계
모표준편차가 6인 정규 모집단에서 10개의 자료를 표본으로 추출하여 다음 결과를 얻었다.
27 34 34 36 30 28 41 35 48 43
(a) 모집단의 평균을 추정하라.   (b) 표준오차를 구하라.   (c) 95% 오차한계를 구하라.
풀이

(a) 점추정 — 모평균의 점추정량은 표본평균 \(\bar{X}\)이다.

$$\hat{\mu} = \bar{X} = \dfrac{1}{10}(27+34+34+36+30+28+41+35+48+43) = \dfrac{356}{10} = 35.6$$
답 (a) \(\hat{\mu} = 35.6\)

(b) 표준오차 — 모분산 σ² = 36이 알려져 있으므로:

$$\text{SE}(\bar{X}) = \dfrac{\sigma}{\sqrt{n}} = \dfrac{6}{\sqrt{10}} \approx 1.897$$
답 (b) \(\text{SE}(\bar{X}) \approx 1.897\)

(c) 95% 오차한계 — 신뢰도 95%이므로 z₀.₀₂₅ = 1.96 사용:

$$z_{0.025} \cdot \dfrac{\sigma}{\sqrt{n}} = 1.96 \times \dfrac{6}{\sqrt{10}} = 1.96 \times 1.897 \approx 3.72$$
답 (c) 95% 오차한계 ≈ 3.72
💡 해석: 모평균은 35.6 ± 3.72, 즉 (31.88, 39.32) 구간에 있다고 95% 신뢰할 수 있다.
예제 6-6 추정값이 참값 근처에 놓일 확률 (표본 크기 영향)
모분산 σ²이 알려진 정규 모집단 N(μ, σ²)에서 크기 n인 표본을 추출하여 \(\hat{\mu} = \bar{X}\)가 μ의 참값 \(\pm\dfrac{\sigma}{4}\) 안에 놓일 확률을 각각 구하라.
(a) n = 20인 경우    (b) n = 100인 경우
풀이

\(\dfrac{\bar{X}-\mu}{\sigma/\sqrt{n}} \sim \text{N}(0,1)\)이므로 다음과 같이 계산할 수 있다.

(a) n = 20인 경우

$$\text{P}\!\left(|\bar{X}-\mu| < \dfrac{\sigma}{4}\right) = \text{P}\!\left(\dfrac{|\bar{X}-\mu|}{\sigma/\sqrt{20}} < \dfrac{\sqrt{20}}{4}\right) = \text{P}(|Z| < 1.12)$$
$$= \Phi(1.12) - \Phi(-1.12) = 2 \times 0.8686 - 1 = \mathbf{0.7372}$$
답 (a) 약 73.72%

(b) n = 100인 경우

$$\text{P}\!\left(|\bar{X}-\mu| < \dfrac{\sigma}{4}\right) = \text{P}\!\left(\dfrac{|\bar{X}-\mu|}{\sigma/\sqrt{100}} < \dfrac{\sqrt{100}}{4}\right) = \text{P}(|Z| < 2.5)$$
$$= \Phi(2.5) - \Phi(-2.5) = 2 \times 0.9938 - 1 = \mathbf{0.9876}$$
답 (b) 약 98.76%
💡 핵심 교훈: 표본 크기 n이 20 → 100으로 5배 커지자, 확률이 73.7% → 98.8%로 급증.
n이 클수록 추정 정밀도가 높아진다 — 5.2에서 \(\text{Var}(\bar{X}) = \sigma^2/n\)이 작아지는 것과 직결된 결과.

$$55.8 - 2.58 \times 1 < \mu < 55.8 + 2.58 \times 1$$
답 \(53.22 < \mu < 58.38\)
💡 \(\sqrt{64} = 8\)이므로 \(\sigma/\sqrt{n} = 8/8 = 1\)로 계산이 단순해진다.
예제 6-9 대표본, 모분산 모름 — 95% 신뢰구간
어느 회사에서 입사시험 평균 성적을 알기 위해 지원자 100명을 무작위로 조사하였더니 평균 성적이 70점, 표본표준편차가 10점이었다. 전체 지원자의 평균 성적의 95% 신뢰구간을 구하라.
풀이
조건 확인: n = 100 ≥ 30 → 대표본, 모분산 σ² 모름 → S 사용, Z-분포 사용

z₀.₀₂₅ = 1.96이고, \(\bar{X} = 70\), S = 10, n = 100이므로:

$$70 - 1.96 \times \dfrac{10}{\sqrt{100}} < \mu < 70 + 1.96 \times \dfrac{10}{\sqrt{100}}$$
$$70 - 1.96 \times 1 < \mu < 70 + 1.96 \times 1$$
답 \(68.04 < \mu < 71.96\)
💡 n = 100이므로 \(\sqrt{100} = 10\), 따라서 \(S/\sqrt{n} = 10/10 = 1\). 대표본이므로 Z-분포 사용 (t 아님).
예제 6-10 소표본, 모분산 모름 — t-분포 활용, 95% 신뢰구간
정규 모집단 N(μ, σ²)에서 크기 10인 표본을 추출하여 다음과 같은 결과를 얻었을 때, 주어진 물음에 답하라.
295 302 310 285 290 198 307 300 291 288
(a) 모평균의 점추정값   (b) 모평균의 표준오차   (c) 모평균의 95% 오차한계   (d) 모평균의 95% 신뢰구간
풀이
조건 확인: n = 10 < 30 → 소표본, σ² 모름 → t-분포 사용, 자유도 = n − 1 = 9

(a) 점추정값

$$\bar{X} = \dfrac{1}{10}(295+302+310+285+290+198+307+300+291+288) = \dfrac{2866}{10} = 286.6$$
답 (a) \(\hat{\mu} = \bar{X} = 286.6\)

(b) 표준오차

표본분산을 구한다:

$$S^2 = \dfrac{1}{n-1}\sum_{i=1}^{n}(X_i - \bar{X})^2 = \dfrac{1}{9}(70.56 + 237.16 + \cdots + 1.96) \approx 1037.38$$
$$S = \sqrt{1037.38} \approx 32.2083$$
$$\text{SE}(\bar{X}) = \dfrac{S}{\sqrt{n}} = \dfrac{32.2083}{\sqrt{10}} \approx 10.185$$
답 (b) \(\text{SE}(\bar{X}) \approx 10.185\)

(c) 95% 오차한계

📌 5.3 t-분포 연결: t₀.₀₂₅(9) = 2.262 (자유도 9인 t-분포표에서)
$$t_{0.025}(n-1)\cdot\dfrac{S}{\sqrt{n}} = 2.262 \times 10.185 \approx 23.038$$
답 (c) 95% 오차한계 ≈ 23.038

(d) 95% 신뢰구간

$$\bar{X} \pm t_{0.025}(9)\dfrac{S}{\sqrt{n}} = 286.6 \pm 23.038$$
답 (d) \((263.562,\; 309.638)\)
💡 비교: 만약 대표본으로 가정하고 z = 1.96을 쓰면 오차한계 = 1.96 × 10.185 ≈ 19.96. t = 2.262를 쓴 결과(23.038)보다 좁은 구간이 된다. 소표본에서 t를 써야 하는 이유가 바로 이것이다.
✅
