🎯 수동 소나 탐지와 가설검정

확률 및 통계 - 가설검정 파트

1. 학습 목표

  • 실제 공학 문제에서 가설검정의 필요성을 이해한다
  • 귀무가설과 대립가설을 올바르게 설정할 수 있다
  • 제1종 오류(False Alarm)와 제2종 오류(Miss)의 의미를 파악한다
  • 가우시안 잡음 환경에서 검정 통계량과 임계값을 계산할 수 있다
  • ROC 곡선을 통해 탐지 성능을 평가할 수 있다

2. 수동 소나 시스템 소개

🚢 상황 설정

잠수함이 수중에서 적 함정의 소리를 탐지하려 합니다. 수동 소나는 능동적으로 신호를 보내지 않고, 주변의 수중 음향을 청취하여 적의 존재를 판단합니다.

문제: 수중에는 항상 해양 잡음(파도, 해류, 생물 소리 등)이 존재합니다. 소나 수신기가 감지한 신호가 단순한 잡음인지, 아니면 적 함정의 신호가 포함된 것인지 어떻게 판단할까요?

📡 시스템 모델

수신 신호 모델:

  • H₀ (귀무가설): 신호 없음 (적 함정 없음)
    X ~ N(0, σ²)
    수신 전압이 평균 0V, 분산 σ²인 가우시안 잡음
  • H₁ (대립가설): 신호 있음 (적 함정 있음)
    X ~ N(A, σ²)
    수신 전압이 평균 A[V], 분산 σ²인 가우시안 분포

여기서:

  • A: 적 함정 신호의 진폭 [V]
  • σ²: 해양 배경 잡음의 분산 (파워)
  • X: 소나 수신기에서 측정된 전압값

3. 가설검정 설정

🎯 가설 설정

가설 의미 확률분포
H₀ 적 함정 없음 (잡음만 존재) X ~ N(0, σ²)
H₁ 적 함정 있음 (신호 + 잡음) X ~ N(A, σ²)

⚖️ 판정 규칙

임계값 γ를 설정하여:

X > γ → H₁ 채택 (적 함정 있다고 판단)
X ≤ γ → H₀ 채택 (적 함정 없다고 판단)

⚠️ 오류의 군사적 의미

  • 제1종 오류 (False Alarm): 적이 없는데 있다고 판단 → 불필요한 회피기동, 전투 준비
  • 제2종 오류 (Miss): 적이 있는데 없다고 판단 → 기습 공격 당할 위험!

4. 오류 확률 계산

📐 제1종 오류 확률 (False Alarm Rate)

H₀가 참일 때, H₁을 채택할 확률:

α = P(X > γ | H₀) = P(X > γ | X ~ N(0, σ²))

표준화하면:

α = P(Z > γ/σ) = Q(γ/σ) = 1 - Φ(γ/σ)

여기서 Q(·)는 표준정규분포의 상측 꼬리 확률, Φ(·)는 표준정규분포의 누적분포함수

📐 제2종 오류 확률 (Miss Rate)

H₁이 참일 때, H₀를 채택할 확률:

β = P(X ≤ γ | H₁) = P(X ≤ γ | X ~ N(A, σ²))

표준화하면:

β = Φ((γ - A)/σ)

🎯 검출 확률 (Detection Probability)

P_D = 1 - β = P(X > γ | H₁) = Q((γ - A)/σ)

💡 핵심 통찰

신호 대 잡음비 (SNR):

SNR = A/σ

SNR이 클수록 (신호가 강하거나 잡음이 약할수록) 탐지가 쉬워집니다!

5. 임계값 설정

🔧 방법 1: 제1종 오류율 고정 (Neyman-Pearson)

허용 가능한 False Alarm 확률 α를 먼저 정하고, 임계값을 결정:

γ = σ × Φ⁻¹(1 - α) = σ × z_{α}

📝 예제 1

해양 잡음의 표준편차 σ = 2V, False Alarm 확률을 α = 0.05로 설정

풀이:

  • z₀.₀₅ = 1.645 (표준정규분포 상위 5% 점)
  • γ = 2 × 1.645 = 3.29V

해석: 수신 전압이 3.29V를 초과하면 적 함정이 있다고 판단

🔧 방법 2: 총 오류 최소화

제1종 오류와 제2종 오류의 가중 합을 최소화:

Cost = C₁ × α + C₂ × β

여기서 C₁, C₂는 각 오류의 비용

7. ROC 곡선 (Receiver Operating Characteristic)

📊 ROC 곡선이란?

임계값 γ를 변화시키면서 False Alarm 확률(P_FA)과 Detection 확률(P_D)의 관계를 나타낸 곡선

  • γ를 낮추면: P_FA ↑, P_D ↑ (민감하게 반응)
  • γ를 높이면: P_FA ↓, P_D ↓ (보수적으로 판단)

✅ 좋은 탐지기의 조건

  • ROC 곡선이 왼쪽 위로 볼록 (좌상단에 가까울수록 우수)
  • 곡선 아래 면적(AUC)이 1에 가까울수록 우수
  • SNR이 높을수록 ROC 성능 향상

9. 다중 샘플 탐지 (확장)

🔬 N개 샘플의 평균 사용

N개의 독립적인 측정값 X₁, X₂, ..., X_N의 평균을 사용하면:

X̄ = (X₁ + X₂ + ... + X_N) / N

평균의 분산이 감소:

Var(X̄) = σ²/N

효과: SNR이 √N 배 향상! → 탐지 성능 대폭 개선

샘플 수 (N) 유효 σ 유효 SNR 성능 개선
1 σ A/σ 기준
4 σ/2 2A/σ 2배
16 σ/4 4A/σ 4배
100 σ/10 10A/σ 10배

10. 정리 및 토론

🎓 핵심 정리

  • 가설검정은 불확실성 하에서 최적의 판단을 내리는 수학적 도구
  • 제1종/제2종 오류는 상충 관계 (trade-off)
  • 임계값 설정은 오류 비용과 운용 조건에 따라 결정
  • SNR 개선이 탐지 성능 향상의 핵심
  • 다중 샘플 평균은 효과적인 SNR 개선 방법
