표본분산과 표본표준편차

모평균이 \(\mu\)이고 모분산이 \(\sigma^2\)인 모집단으로부터 추출한 크기 \(n\)인 확률표본을 \(X_1, X_2, \cdots, X_n\)이라 할 때, 모분산의 추정량인 표본분산은 다음과 같이 정의한다.

\[S^2 = \dfrac{1}{n-1}\sum_{i=1}^{n}(X_i - \overline{X})^2\]

무한 모집단으로부터 확률표본을 추출하여 얻은 표본분산 \(S^2\)은 다음 성질을 갖는다.

\[\mathrm{E}(S^2) = \sigma^2\]

따라서 \(S^2\)은 모분산 \(\sigma^2\)의 불편추정량이다. 모표준편차 \(\sigma\)의 추정량인 표본표준편차(sample standard deviation)는 다음과 같이 정의한다.

\[S = \sqrt{\dfrac{1}{n-1}\sum_{i=1}^{n}(X_i - \overline{X})^2}\]
주의: \(\mathrm{E}(S) < \sigma\)이므로 표본표준편차 \(S\)는 모표준편차 \(\sigma\)의 불편추정량이 아니다. 그러나 표본의 크기 \(n\)이 크면(\(n > 30\)) 편향이 작아서 \(S\)를 \(\sigma\)의 추정량으로 사용할 수 있다.

모평균 \(\mu\)를 아는 경우 — 모분산 \(\sigma^2\)의 구간추정

정규분포 \(\mathrm{N}(\mu,\,\sigma^2)\)을 따르는 모집단에서 모평균 \(\mu\)를 알 때, 미지의 모분산 \(\sigma^2\)의 신뢰구간을 구해보자. 다음과 같이 정의한 \(\chi^2\)-통계량은 자유도 \(n\)인 \(\chi^2\)-분포를 따른다.

\[\dfrac{\displaystyle\sum_{i=1}^{n}(X_i - \mu)^2}{\sigma^2} \;\sim\; \chi^2(n) \;=\; \sum_{i=1}^{n}Z_i^2\]
왜 이렇게 되는가?
\(X_i \sim \mathrm{N}(\mu,\,\sigma^2)\)이면 표준화 변환 \(Z_i = \dfrac{X_i - \mu}{\sigma}\)에 의해 \(Z_i \sim \mathrm{N}(0,\,1)\) (표준정규분포)이다. 표준정규 확률변수를 제곱하면 자유도 1인 카이제곱 분포를 따르고 (\(Z_i^2 \sim \chi^2(1)\)), 서로 독립인 \(n\)개를 더하면 자유도 \(n\)인 카이제곱 분포를 따른다: \[\sum_{i=1}^{n} Z_i^2 = \sum_{i=1}^{n}\dfrac{(X_i-\mu)^2}{\sigma^2} = \dfrac{\displaystyle\sum_{i=1}^{n}(X_i-\mu)^2}{\sigma^2} \sim \chi^2(n)\] 따라서 이 통계량을 \(\chi^2\)로 표기하고 자유도 \(n\)인 카이제곱 분포를 이용하여 신뢰구간을 구한다.

임의의 양수 \(\alpha\;(0 < \alpha < 1)\)에 대하여 다음이 성립한다.

\[\mathrm{P}\!\left(\chi^2_{1-\alpha/2}(n) < \chi^2 < \chi^2_{\alpha/2}(n)\right) = 1 - \alpha\]
이 확률 식은 어떻게 나오는가?
카이제곱 분포 \(\chi^2(n)\)의 확률밀도함수는 오른쪽으로 긴 꼬리를 갖는 비대칭 분포이다. 우리는 양쪽 꼬리에 각각 확률 \(\alpha/2\)씩을 남기고 싶다. 즉, \[\mathrm{P}\!\left(\chi^2 \leq \chi^2_{1-\alpha/2}(n)\right) = \dfrac{\alpha}{2}, \qquad \mathrm{P}\!\left(\chi^2 \geq \chi^2_{\alpha/2}(n)\right) = \dfrac{\alpha}{2}\] 여기서 \(\chi^2_{1-\alpha/2}(n)\)은 하위 \(100(\alpha/2)\%\) 점 (왼쪽 꼬리), \(\chi^2_{\alpha/2}(n)\)은 상위 \(100(\alpha/2)\%\) 점 (오른쪽 꼬리)이다. 따라서 두 임계값 사이에 \(\chi^2\)이 놓일 확률은 \[1 - \dfrac{\alpha}{2} - \dfrac{\alpha}{2} = 1 - \alpha\] 이 되어 위 식이 성립한다.
📊 카이제곱 분포 — 면적과 확률의 관계
중앙 면적 = 1 − α  (신뢰수준) 양쪽 꼬리 합 = α  (유의수준)

여기서 \(\chi^2_{1-\alpha/2}(n)\)과 \(\chi^2_{\alpha/2}(n)\)은 각각 \(100(\alpha/2)\%\) 점과 \(100(1-\alpha/2)\%\) 점이다. 앞의 식에 \(\chi^2\)-통계량을 대입하면 다음과 같다.

\[\mathrm{P}\!\left(\chi^2_{1-\alpha/2}(n) < \dfrac{\displaystyle\sum_{i=1}^{n}(X_i-\mu)^2}{\sigma^2} < \chi^2_{\alpha/2}(n)\right) = 1-\alpha\]

좌변의 괄호 속 부등식을 \(\sigma^2\)에 대해 풀면 다음과 같이 쓸 수 있다.

\[\mathrm{P}\!\left(\dfrac{\displaystyle\sum_{i=1}^{n}(X_i-\mu)^2}{\chi^2_{\alpha/2}(n)} < \sigma^2 < \dfrac{\displaystyle\sum_{i=1}^{n}(X_i-\mu)^2}{\chi^2_{1-\alpha/2}(n)}\right) = 1-\alpha\]
정리 6-14
모평균을 아는 경우 모분산의 구간추정

모평균 \(\mu\)를 알 때, 모분산 \(\sigma^2\)의 \(100(1-\alpha)\%\) 신뢰구간은 다음과 같다.

\[\left(\dfrac{\displaystyle\sum_{i=1}^{n}(X_i-\mu)^2}{\chi^2_{\alpha/2}(n)},\quad \dfrac{\displaystyle\sum_{i=1}^{n}(X_i-\mu)^2}{\chi^2_{1-\alpha/2}(n)}\right)\]

정규분포 \(\mathrm{N}(35,\,\sigma^2)\)을 따르는 모집단에서 크기가 10인 표본을 추출하였더니 다음과 같았다고 할 때, 모분산의 95% 신뢰구간을 구하라.

27   34   34   36   30   28   41   35   48   43
풀이

주어진 관측값 \(X_i\)에 대하여 \(X_i\)와 모평균 \(\mu = 35\)의 편차제곱을 계산한다.

\(X_i\) 2734343630 2841354843
\(X_i - \mu\) −8−1−11−5 −760138
\((X_i-\mu)^2\) 6411125 4936016964

그러면

\[\sum_{i=1}^{10}(X_i-\mu)^2 = 410\]

95% 신뢰구간이므로 \(\alpha = 0.05\). \(\chi^2_{0.025}(10) = 20.48,\quad \chi^2_{0.975}(10) = 3.25\)

따라서 [정리 6-14]에 따라 \(\sigma^2\)의 95% 신뢰구간은 다음과 같다.

\[\dfrac{410}{20.48} < \sigma^2 < \dfrac{410}{3.25}\] \[20.02 < \sigma^2 < 126.15\]
전자공학 예제 1 — 저항값 품질 검사
💡 배경 지식: 회로를 설계할 때 사용하는 저항(resistor)에는 제조 공차(tolerance)가 있다. 예를 들어 "100 Ω ± 5%" 저항이라면 실제 저항값이 95~105 Ω 사이에 분포한다. 저항값의 분산이 크다는 것은 제품 품질이 일정하지 않다는 뜻이다. 제조사가 "이 저항들의 모평균은 정확히 100 Ω으로 조정되어 있다"고 보증한 경우, 실제 분산을 추정해 품질을 검증할 수 있다.

어떤 제조사에서 생산한 100 Ω 저항의 실제 저항값이 \(\mathrm{N}(100,\,\sigma^2)\)을 따른다고 한다. (모평균 \(\mu = 100\) Ω을 제조사가 보증) 품질 검사를 위해 10개를 무작위로 추출하여 정밀 측정하였더니 다음과 같았다 (단위: Ω). 모분산 \(\sigma^2\)의 95% 신뢰구간을 구하라.

98.2   101.5   99.8   100.3   102.1   97.6   100.9   101.4   99.1   99.1
풀이

모평균 \(\mu = 100\)을 알고 있으므로 [정리 6-14]를 적용한다.

\(X_i\) (Ω) 98.2101.599.8100.3102.1 97.6100.9101.499.199.1
\(X_i - 100\) −1.81.5−0.20.32.1 −2.40.91.4−0.9−0.9
\((X_i-100)^2\) 3.242.250.040.094.41 5.760.811.960.810.81
\[\sum_{i=1}^{10}(X_i - 100)^2 = 3.24 + 2.25 + 0.04 + 0.09 + 4.41 + 5.76 + 0.81 + 1.96 + 0.81 + 0.81 = 20.18\]

95% 신뢰구간이므로 \(\alpha = 0.05\),  자유도 \(n = 10\). \[\chi^2_{0.025}(10) = 20.48, \qquad \chi^2_{0.975}(10) = 3.25\]

\[\dfrac{20.18}{20.48} < \sigma^2 < \dfrac{20.18}{3.25}\] \[0.985 < \sigma^2 < 6.209\]
해석: 모분산 \(\sigma^2\)의 95% 신뢰구간은 약 \((0.99,\ 6.21)\) (Ω²)이다. 표준편차로 환산하면 약 \(0.99 \sim 2.49\) Ω. 만약 설계 규격이 "표준편차 1 Ω 이하"라면, 신뢰구간 하한이 이미 규격을 넘을 가능성이 있으므로 추가 검사가 필요하다는 판단을 내릴 수 있다.

모평균 \(\mu\)를 모르는 경우 — 모분산 \(\sigma^2\)의 구간추정

정규분포 \(\mathrm{N}(\mu,\,\sigma^2)\)을 따르는 모집단에서 모평균 \(\mu\)를 모를 때, 미지의 모분산 \(\sigma^2\)의 신뢰구간을 구해보자. 다음과 같이 정의한 \(\chi^2\)-통계량은 자유도 \((n-1)\)인 \(\chi^2\)-분포를 따른다.

\[\chi^2 = \dfrac{(n-1)S^2}{\sigma^2}\]

따라서 임의의 양수 \(\alpha\;(0 < \alpha < 1)\)에 대하여 다음이 성립한다.

\[\mathrm{P}\!\left(\chi^2_{1-\alpha/2}(n-1) < \dfrac{(n-1)S^2}{\sigma^2} < \chi^2_{\alpha/2}(n-1)\right) = 1-\alpha\]

위 식에서 좌변의 괄호 속 부등식을 \(\sigma^2\)에 대해 풀면 다음과 같이 쓸 수 있다.

\[\mathrm{P}\!\left(\dfrac{(n-1)S^2}{\chi^2_{\alpha/2}(n-1)} < \sigma^2 < \dfrac{(n-1)S^2}{\chi^2_{1-\alpha/2}(n-1)}\right) = 1-\alpha\]
정리 6-15
모평균을 모르는 경우 모분산의 구간추정

모평균 \(\mu\)를 모를 때, 모분산 \(\sigma^2\)의 \(100(1-\alpha)\%\) 신뢰구간은 다음과 같다.

\[\left(\dfrac{(n-1)S^2}{\chi^2_{\alpha/2}(n-1)},\quad \dfrac{(n-1)S^2}{\chi^2_{1-\alpha/2}(n-1)}\right)\]
예제 6-24

계란의 규격은 무게에 따라 왕란(68g 이상), 특란(60~68g), 대란(52~60g), 중란(44~52g), 소란(44g 미만)으로 나뉜다. 이는 양계장에서 생산한 중란의 무게를 알아보기 위해 7개의 계란을 임의로 추출하여 무게를 측정한 결과가 다음과 같았다. 측정값의 분포가 정규분포를 따른다고 가정할 때, 모분산의 95% 신뢰구간을 구하라.

45   47   44   48   46   45   47
풀이

신뢰구간을 구하기 위해 필요한 값을 구한다.

\[\overline{X} = \dfrac{1}{7}(45 + 47 + \cdots + 47) = 46\]
\[S^2 = \dfrac{1}{7-1}\left[(45-46)^2 + (47-46)^2 + \cdots + (47-46)^2\right] = 2\]
\[\chi^2_{0.975}(6) = 1.24, \qquad \chi^2_{0.025}(6) = 14.45\]

[정리 6-15]에 따라 \(\sigma^2\)의 95% 신뢰구간은 다음과 같다.

\[\dfrac{6 \times 2}{14.45} < \sigma^2 < \dfrac{6 \times 2}{1.24}\] \[0.83 < \sigma^2 < 9.677\]
전자공학 예제 2 — ADC 전압 측정 노이즈 분석
💡 배경 지식: ADC(Analog-to-Digital Converter, 아날로그-디지털 변환기)는 마이크로컨트롤러(Arduino, STM32 등)에 내장되어 있으며, 아날로그 전압을 디지털 숫자로 변환해 준다. 실제 측정 시에는 회로의 노이즈(noise) 때문에 동일한 전압을 반복 측정해도 값이 조금씩 다르게 나온다. 이 측정 변동(분산)을 추정하면 센서 시스템의 신뢰성을 평가할 수 있다. 모평균(실제 전압)을 모르는 상황이므로 [정리 6-15]를 사용한다.

Arduino의 ADC로 일정한 기준 전압을 8회 반복 측정하였더니 다음과 같은 값을 얻었다 (단위: mV). 측정값이 정규분포를 따른다고 가정할 때, 모분산 \(\sigma^2\)의 95% 신뢰구간을 구하라. (모평균 전압은 알 수 없다.)

3302   3298   3305   3301   3299   3303   3297   3303
풀이

\(n = 8\)이므로 먼저 표본평균 \(\overline{X}\)와 표본분산 \(S^2\)을 계산한다.

\[\overline{X} = \dfrac{3302 + 3298 + 3305 + 3301 + 3299 + 3303 + 3297 + 3303}{8} = \dfrac{26408}{8} = 3301\text{ (mV)}\]
\(X_i\) (mV) 3302329833053301 3299330332973303
\(X_i - \overline{X}\) 1−340 −22−42
\((X_i-\overline{X})^2\) 19160 44164
\[\sum_{i=1}^{8}(X_i-\overline{X})^2 = 1+9+16+0+4+4+16+4 = 54\]
\[S^2 = \dfrac{54}{8-1} = \dfrac{54}{7} \approx 7.714 \text{ (mV}^2\text{)}\]

95% 신뢰구간이므로 \(\alpha = 0.05\),  자유도 \(n-1 = 7\). \[\chi^2_{0.025}(7) = 16.01, \qquad \chi^2_{0.975}(7) = 1.69\]

[정리 6-15]에 따라

\[\dfrac{7 \times 7.714}{16.01} < \sigma^2 < \dfrac{7 \times 7.714}{1.69}\] \[\dfrac{54}{16.01} < \sigma^2 < \dfrac{54}{1.69}\] \[3.37 < \sigma^2 < 31.95\text{ (mV}^2\text{)}\]
해석: 모분산 \(\sigma^2\)의 95% 신뢰구간은 약 \((3.37,\ 31.95)\) mV²이다. 표준편차로 환산하면 약 \(1.84 \sim 5.65\) mV. ADC 설계 사양에서 노이즈 표준편차 기준이 "3 mV 이하"라면, 신뢰구간의 하한도 이미 이 기준을 초과할 수 있으므로 회로 개선이나 필터링이 필요함을 시사한다.
