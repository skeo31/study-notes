5.1  모집단과 표본분포

Population & Sampling Distribution
1
기본 개념 — 모집단, 표본, 오차
[그림 5-0] 모집단에서 표본추출의 흐름
🌐 모집단 (Population)

통계조사 대상 전체를 의미한다.

예: 우리나라 성인 남성 전체, 공장에서 생산된 전체 제품 등

📦 표본분포 (Sampling Distribution)

전체 중 일부를 표본으로 추출했을 때, 그 자료에 대한 확률분포를 표본분포라 한다.

⚠️ 표본오차 (Sampling Error)

표본추출 과정에서 필연적으로 발생하는 오차.

표본이 모집단을 완전히 대표하지 못해 생기는 차이

🚫 비표본오차 (Non-sampling Error)

응답자가 정확하게 응답하지 않아 발생하는 오차.

예: 무응답, 응답 오기입, 측정 도구 오류 등

3
표본추출법 — 확률 vs 비확률
✅ 확률추출법 (Probability Sampling)

모집단의 각 개체가 표본으로 뽑힐 가능성이 모두 동등하다는 조건에서 객관적으로 표본을 추출하는 방법

= 임의추출법 (random sampling)

→ 추출된 표본: 확률표본 또는 임의표본

❌ 비확률추출법 (Nonprobability Sampling)

모집단으로부터 표본을 추출할 때, 주관적으로 모집단의 대표를 정하여 표본을 추출하는 방법

→ 편의(convenience) 표본, 판단(judgment) 표본 등

확률추출법 vs 비확률추출법 비교
4
확률추출법의 종류
① 단순임의추출법 (Simple Random Sampling)

표본을 동등한 확률로 추출하는 방법. 제비뽑기, 난수표, 컴퓨터 난수 이용.

② 층화임의추출법 (Stratified Random Sampling)

모집단을 성질이 비슷한 것끼리 층(stratum)으로 분류하고, 각 층으로부터 임의로 표본을 추출하는 방법

③ 계통임의추출법 (Systematic Random Sampling)

모집단으로부터 일정한 간격 k를 두고 추출하는 방법. 임의출발점 i를 정하고 그로부터 k번째마다 표본을 뽑는다.

이때 k를 추출 간격 (sampling interval)이라 한다.

\[ i \;,\; i+k \;,\; i+2k \;,\; \cdots \;,\; i+jk \;,\; \cdots \;,\; i+(n-1)k \]
④ 집락추출법 (Cluster Sampling)

모집단을 여러 개의 집락(cluster)으로 나누고, 그 집락을 추출 단위로 하여 몇 개의 집락을 임의로 선택한 뒤 선택된 집락 내부 전체를 조사하는 방법이다.

집락은 학교·마을·공장 라인처럼 자연적으로 이미 존재하는 군집을 그대로 사용한다. 인위적으로 최적화해 만드는 것이 아니다.

  • 전체 목록(sampling frame)이 없어도 집락 목록만 있으면 적용 가능
  • 지리적으로 분산된 모집단에서 비용·시간을 크게 절감할 수 있음
  • 집락 내 개체가 서로 비슷할수록(동질적) 표본오차가 커지는 단점이 있음
  • 확률비례추출법(PPS): 집락 크기가 서로 다를 때, 큰 집락이 더 높은 확률로 선택되도록 조정
⚠️ "집락 내부는 이질적, 집락 간은 동질적" — 왜 머신러닝 클러스터링과 반대일까?
💻 머신러닝 클러스터링
목적: 비슷한 것끼리 묶기
클러스터 내부: 동질적 ✔
클러스터 간: 이질적 ✔
클러스터를 알고리즘이 최적화해서 생성
📊 통계학 집락추출법
목적: 모집단을 잘 대표하는 표본 뽑기
집락 내부: 이질적이어야 이상적
집락 간: 동질적이어야 이상적
집락은 자연적으로 이미 존재하는 군집
집락추출법에서는 선택된 집락만 조사하고 나머지는 완전히 제외한다. 따라서 선택된 집락 하나가 모집단 전체를 축소판처럼 대표해야 한다.
📌 예시: 전국 학생 수학 성적 조사
❌ 집락 내부가 동질적인 경우 (나쁜 설계)
집락 A = 강남 학교들만
집락 B = 농촌 학교들만
집락 C = 특목고들만

→ 집락 A 선택 시: 상위권만 조사됨
→ 나머지 유형은 완전히 누락
→ 모집단 전체를 대표 못함 😥
✅ 집락 내부가 이질적인 경우 (좋은 설계)
집락 A = 강남·강북·농촌 학생 혼합
집락 B = 상·중·하위권 학생 혼합
집락 C = 특목고·일반고·직업고 혼합

→ 집락 A 하나만 선택해도
→ 다양한 유형이 포함됨
→ 모집단을 잘 대표함 😊
집락 간이 동질적이어야 하는 이유: 집락들이 서로 비슷하면 어떤 집락을 선택해도 비슷한 결론이 나온다. 즉 "어떤 집락이 뽑혔느냐"에 따른 결과의 편차가 작아져 표본오차가 줄어든다. 반대로 집락들이 서로 크게 다르면, 운 나쁘게 편향된 집락을 뽑았을 때 결과가 크게 왜곡된다.
구분 머신러닝 클러스터링 통계학 집락추출법
목적 비슷한 것끼리 묶기 모집단을 잘 대표하는 표본 추출
집락 내부 동질적이어야 좋음 이질적이어야 좋음
집락 간 이질적이어야 좋음 동질적이어야 좋음
집락 형성 알고리즘이 최적화해서 생성 자연적으로 이미 존재하는 군집
예시 — 수학 성적 조사: 동질 집락(나쁨) vs 이질 집락(좋음)
⚡ 층화임의추출법 vs 집락추출법 — 헷갈리기 쉬운 차이!
층화임의추출법
· 모든 층에서 일부만 추출
· 층 내부: 동질적 (같은 특성)
· 층 간: 이질적 (서로 다른 특성)
· 정밀도 ↑, 비용 ↑
집락추출법
· 선택된 집락 내부 전부 조사
· 집락 내부: 이질적 (다양한 특성)
· 집락 간: 동질적 (서로 비슷)
· 정밀도 ↓, 비용 ↓
⑤ 다단추출법 (Multistage Sampling)

집락추출법에서 한 발 더 나아가, 선택된 집락 내부에서도 전부를 조사하지 않고 다시 표본을 추출하는 방법이다. 이렇게 2단계 이상으로 추출을 반복하는 것을 다단추출법이라 한다.

집락의 크기가 매우 클 때 비용 절감은 물론이고, 잘 설계하면 정밀도 면에서도 유리한 경우가 많다.

  • 1단 추출: 모집단 전체 집락 중 일부 집락을 임의 선택
  • 2단 추출: 선택된 집락 내부에서 다시 개체를 임의 추출
  • 3단 이상: 2단에서 얻은 소집락에서 또 추출 (예: 시·도 → 시·군·구 → 개인)
  • 각 단계에서 어떤 확률추출법도 사용 가능 (단순임의, 층화, 계통 등 조합 가능)
예시 — 전국 가구 소득 조사 (3단 추출)
⚡ 집락추출법 vs 다단추출법 — 핵심 차이
집락추출법
집락 선택 후 →
내부 전원 조사
비용↓ but 선택 안 된 집락은 완전 제외
다단추출법
집락 선택 후 →
내부에서 다시 추출
비용↓↓ + 정밀도 개선 가능
💡 실무 팁: 대규모 국가통계(인구총조사, 가계동향조사 등)는 대부분 다단추출법을 사용하며, 각 단계에서 층화추출과 계통추출을 혼합해 정밀도를 높인다.

확률추출법 종류 정리
추출법 핵심 원리 적합한 상황
단순임의추출법 동등 확률, 무작위 선택 모집단이 균질하고 목록화 가능할 때
층화임의추출법 층 분류 후 각 층에서 임의 추출 모집단이 이질적 하위집단으로 구성될 때
계통임의추출법 간격 k마다 추출 모집단이 순서대로 나열되어 있을 때
집락추출법 집락(군집) 단위로 추출 모집단이 지리적으로 분산되어 있을 때
다단추출법 집락 선택 후 내부 재추출 집락이 크고 비용 절감이 필요할 때
