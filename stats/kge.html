통계학 · 표본 평균의 분산

$k$개 세트, 세트당 $n$개 요소일 때
공식 유도

설정 기본 설정

  • 모집단: 평균 $\mu$, 분산 $\sigma^2$
  • $k$개의 표본 세트를 추출
  • 각 세트는 $n$개의 관측값으로 구성
  • $j$번째 세트의 $i$번째 관측값: $X_{ij}$

Step 1 각 세트의 표본 평균

$j$번째 세트의 표본 평균:

$$\bar{X}_j = \frac{1}{n}\sum_{i=1}^{n} X_{ij}, \quad j = 1, 2, \ldots, k$$

각 관측값은 모집단에서 복원추출되었으므로:

$$E(X_{ij}) = \mu, \quad \text{Var}(X_{ij}) = \sigma^2$$

Step 2 각 세트 표본 평균의 기댓값과 분산

$$E(\bar{X}_j) = \frac{1}{n}\sum_{i=1}^{n}E(X_{ij}) = \frac{1}{n} \cdot n\mu = \mu$$ $$\text{Var}(\bar{X}_j) = \frac{1}{n^2}\sum_{i=1}^{n}\text{Var}(X_{ij}) = \frac{1}{n^2} \cdot n\sigma^2 = \frac{\sigma^2}{n}$$
여기까지가 교과서의 유도입니다.
$\bar{X}_j$ 하나가 이미 $\text{Var}(\bar{X}_j) = \dfrac{\sigma^2}{n}$을 가집니다.
세트를 몇 번 반복하든($k$에 관계없이) 이 값은 고정입니다.

Step 3 $k$세트 표본 평균들의 전체 평균

$k$개의 $\bar{X}_j$를 다시 평균 냅니다:

$$\bar{\bar{X}} = \frac{1}{k}\sum_{j=1}^{k}\bar{X}_j$$

기댓값:

$$E(\bar{\bar{X}}) = \frac{1}{k}\sum_{j=1}^{k}E(\bar{X}_j) = \frac{1}{k} \cdot k\mu = \mu$$

분산:

$$\text{Var}(\bar{\bar{X}}) = \frac{1}{k^2}\sum_{j=1}^{k}\text{Var}(\bar{X}_j) = \frac{1}{k^2} \cdot k \cdot \frac{\sigma^2}{n} = \frac{\sigma^2}{kn}$$
세트 수 $k$가 늘어날수록 분산이 $\dfrac{\sigma^2}{kn}$으로 더 작아집니다.
즉, 반복 추출을 많이 할수록 전체 평균은 더 정밀해집니다.

정리 핵심 비교 정리

대상 기호 기댓값 분산
개별 관측값 $X_{ij}$ $\mu$ $\sigma^2$
한 세트의 표본 평균 $\bar{X}_j$ $\mu$ $\dfrac{\sigma^2}{n}$
$k$세트 평균들의 평균 $\bar{\bar{X}}$ $\mu$ $\dfrac{\sigma^2}{kn}$

요약

  • 세 레벨 모두 기댓값은 $\mu$ — 모두 불편추정량
  • $n$이 커질수록 한 세트의 표본 평균 분산 $\dfrac{\sigma^2}{n}$이 감소
  • $k$가 커질수록 전체 평균의 분산 $\dfrac{\sigma^2}{kn}$이 추가로 감소
  • 교과서 공식 $\text{Var}(\bar{X}) = \dfrac{\sigma^2}{n}$은 $k=1$이거나 세트 하나의 분산을 말할 때 해당
