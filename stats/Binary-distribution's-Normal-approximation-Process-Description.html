📈 이항분포의 정규근사 과정

Binomial Distribution → Normal Distribution Approximation

🎯 이항분포란?

이항분포 B(n, p)는 n번의 독립적인 베르누이 시행에서 성공 횟수를 나타내는 이산 확률분포입니다.

📚 이항분포의 정의

각 시행에서 성공 확률이 p일 때, n번 시행 중 k번 성공할 확률:

P(X = k) = C(n, k) × pk × (1-p)n-k

여기서 C(n, k) = n! / (k!(n-k)!) 는 조합(combination)입니다.

이항분포의 특성

평균(기댓값): E[X] = np
분산: Var[X] = np(1-p)
표준편차: σ = √(np(1-p))
💡 예시: 동전 던지기

공정한 동전(p=0.5)을 10번 던질 때, 앞면이 나오는 횟수 X는 B(10, 0.5)를 따릅니다.

E[X] = 10 × 0.5 = 5
Var[X] = 10 × 0.5 × 0.5 = 2.5
σ = √2.5 ≈ 1.58

🔄 왜 정규분포로 근사하는가?

⚠️ 이항분포 계산의 어려움

n이 커질수록 이항분포의 확률을 직접 계산하는 것이 매우 어려워집니다:

  • 팩토리얼 계산 복잡도: C(100, 50) = 100! / (50! × 50!) 같은 큰 수 계산
  • 계산량: P(X ≤ k)를 구하려면 0부터 k까지 모두 더해야 함
  • 컴퓨터 오버플로우: 큰 n에서는 수치적으로 불안정
✨ 정규근사의 장점
  • 계산 간편: 표준정규분포표(Z-table)만 있으면 됨
  • 빠른 속도: 표준화 → 표 참조 (2단계만)
  • 높은 정확도: n이 충분히 크면 매우 정확

거의 정규분포!

↓ n이 증가할수록 이항분포는 종 모양(bell-shaped)의 정규분포에 가까워집니다!

📐 정규근사의 이론적 기반: 중심극한정리

🎓 중심극한정리 (Central Limit Theorem)

독립적이고 동일한 분포를 따르는 확률변수들의 합(또는 평균)은 n이 충분히 크면 정규분포에 근사합니다.

이항분포와의 연결:

이항분포 X ~ B(n, p)는 n개의 독립적인 베르누이 확률변수의 합입니다:

X = X₁ + X₂ + ... + Xₙ

여기서 각 Xi는 베르누이(p)를 따르므로, 중심극한정리에 의해 n이 크면 X는 정규분포에 근사합니다!

💡 직관적 이해

동전을 많이 던질수록 앞면이 나오는 비율은 0.5 근처에 몰리게 되고, 이 분포는 점점 종 모양의 대칭적인 형태(정규분포)를 띠게 됩니다. 이것이 바로 중심극한정리의 마법입니다!

🔢 정규근사 과정: 단계별 가이드

1 조건 확인

정규근사를 사용하기 전에 먼저 다음 조건을 확인해야 합니다:

np ≥ 5 그리고 n(1-p) ≥ 5

두 조건을 모두 만족해야 정규근사가 충분히 정확합니다.

2 정규분포 파라미터 계산

이항분포 B(n, p)를 정규분포 N(μ, σ²)로 근사할 때:

평균: μ = np
분산: σ² = np(1-p)
표준편차: σ = √(np(1-p))
X ~ B(n, p) → X ~ N(np, np(1-p))
3 연속성 수정 (Continuity Correction)

이산분포를 연속분포로 근사하므로 0.5를 더하거나 빼야 합니다:

이항분포 정규근사 (연속성 수정)
P(X = k) P(k - 0.5 ≤ X ≤ k + 0.5)
P(X ≤ k) P(X ≤ k + 0.5)
P(X ≥ k) P(X ≥ k - 0.5)
P(X < k) P(X ≤ k - 0.5)
P(X > k) P(X ≥ k + 0.5)
4 표준화 (Standardization)

X를 표준정규분포 Z로 변환합니다:

Z = (X - μ) / σ = (X - np) / √(np(1-p))

이제 Z ~ N(0, 1) (표준정규분포)를 따릅니다.

5 표준정규분포표 사용

표준정규분포표(Z-table)를 이용하여 확률을 구합니다:

P(Z ≤ z) = Φ(z)

Φ(z)는 표준정규분포의 누적분포함수(CDF)입니다.

📝 완전한 예제: 단계별 풀이

🎯 문제

어느 공장에서 생산되는 제품의 불량률은 10%입니다. 200개의 제품을 검사할 때, 불량품이 15개 이하일 확률을 구하세요.

1 문제 파악 및 조건 확인
n = 200 (제품 개수)
p = 0.1 (불량률)
X ~ B(200, 0.1)
구하는 것: P(X ≤ 15)

조건 확인:

np = 200 × 0.1 = 20 ≥ 5 ✅
n(1-p) = 200 × 0.9 = 180 ≥ 5 ✅

→ 정규근사 사용 가능!

2 정규분포 파라미터 계산
μ = np = 200 × 0.1 = 20
σ² = np(1-p) = 200 × 0.1 × 0.9 = 18
σ = √18 ≈ 4.243
X ~ N(20, 18) 또는 N(20, 4.243²)
3 연속성 수정 적용

P(X ≤ 15)를 구하므로:

P(X ≤ 15) ≈ P(X ≤ 15.5)

"이하"이므로 상한에 0.5를 더합니다.

4 표준화
Z = (X - μ) / σ
Z = (15.5 - 20) / 4.243
Z = -4.5 / 4.243
Z ≈ -1.06
5 표준정규분포표 사용
P(X ≤ 15.5) = P(Z ≤ -1.06)
= Φ(-1.06)
= 1 - Φ(1.06) (대칭성 이용)
= 1 - 0.8554
≈ 0.1446

최종 답: 약 14.46%

200개 제품 중 불량품이 15개 이하일 확률은 약 14.46%입니다.

⚠️ 주의사항 및 팁

🚨 흔한 실수
  1. 조건 미확인: np ≥ 5, n(1-p) ≥ 5를 확인하지 않고 근사 사용
  2. 연속성 수정 누락: 0.5 더하기/빼기를 잊어버림
  3. 부호 실수: "이상/이하/초과/미만"에 따른 0.5 방향 착각
  4. 표준화 오류: μ, σ 계산 실수 또는 공식 혼동
💡 성공을 위한 팁
  • 체크리스트 사용: 5단계를 순서대로 확인
  • 그림 그리기: 정규분포 곡선을 그려서 구하는 영역 표시
  • 검산: 확률이 0~1 사이인지, 합리적인 값인지 확인
  • 연습: 다양한 문제 유형을 반복 연습
