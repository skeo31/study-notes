Z점수
하나의 관측값이 평균에서 얼마나 떨어져 있는지 나타낼 때 사용하는 이름.
Z = (X − μ) / σ

Z변환 (표준화)
임의의 정규분포 전체를 표준 정규분포 N(0,1)로 바꾸는 변환으로 부를 때.
Z = (X − μ) / σ

공식은 완전히 동일합니다. "한 값의 상대적 위치를 구한다"고 볼 때는 Z점수, "분포 전체를 N(0,1)로 옮긴다"고 볼 때는 Z변환이라고 부를 뿐입니다. 교재마다 다른 이름을 쓰더라도 당황하지 마세요.

왜 Z점수가 필요할까?

시험 결과를 비교해 봅시다. 물리 시험에서 75점, 수학 시험에서 82점을 받았다면 어떤 시험을 더 잘 본 걸까요? 단순히 점수만 보면 수학을 더 잘 본 것 같지만, 물리 시험 평균이 60점이고 수학 평균이 90점이라면 이야기가 달라집니다.

서로 다른 척도를 가진 데이터를 비교하려면 표준화(standardization)가 필요합니다. Z점수(=Z변환)는 모든 정규분포를 평균 0, 표준편차 1인 표준 정규분포 N(0,1)로 변환해 줍니다.

Z점수 공식
Z = (X − μ) / σ
X: 관측값  |  μ (뮤): 모집단 평균  |  σ (시그마): 모집단 표준편차
X
내가 비교하고 싶은 관측값
μ
전체 데이터의 평균값
σ
전체 데이터의 표준편차

Z점수는 "평균으로부터 표준편차 몇 개 만큼 떨어져 있는가"를 나타냅니다. 단위가 없는 순수한 수치이므로 어떤 분포끼리도 비교할 수 있습니다.

📘 어느 시험을 더 잘 봤을까?

물리: X=75, μ=60, σ=15  |  수학: X=82, μ=90, σ=8

1
물리 Z점수: Z = (75−60)/15 = 1.00 → 상위 약 15.9%
2
수학 Z점수: Z = (82−90)/8 = −1.00 → 하위 약 15.9%
3
점수는 수학이 높지만, 상대적으로는 물리를 훨씬 잘 본 것입니다. Z점수 없이는 알 수 없는 사실이에요.
🔧 제조 공정 품질 관리

볼트 직경 규격: μ=10.00mm, σ=0.05mm. 측정값 X=10.12mm — 불량 판정 기준은 |Z|>2.5

1
Z = (10.12 − 10.00) / 0.05 = 2.40
2
|Z| = 2.40 < 2.5 → 정상 범위 내 (불량 아님)
3
공학에서는 이런 방식으로 품질 허용 범위(공정 능력)를 Z점수로 표현합니다.
🔄 역방향 문제: X 구하기

강의 성적 μ=70, σ=12. 상위 10%에 들려면 최소 몇 점이 필요한가?

1
상위 10% → 누적 확률 0.90 → Z표에서 Z = 1.28
2
공식 역산: X = μ + Z·σ = 70 + 1.28×12 = 85.36점
3
최소 86점 (올림)을 받아야 상위 10%에 진입합니다.
