00 출발점: 표준 정규분포 Z

카이제곱 분포와 레일리 분포는 모두 표준 정규분포 Z ~ N(0, 1)에서 출발합니다. 이 두 분포는 새로운 개념이 아니라, 이미 알고 있는 정규분포에 제곱(²)과 제곱근(√) 이라는 연산을 적용한 결과입니다.

표준 정규분포 PDF
f(z)  =  1 √(2π)   exp (− z2 2 )  ,   z ∈ (−∞, +∞)
평균 = 0, 분산 = 1 / 좌우 대칭 / 대부분의 측정 오차, 잡음이 이 분포를 따름
왜 정규분포가 출발점인가?
전자 회로에서 발생하는 열잡음(Thermal Noise)과 측정 오차는 자연적으로 정규분포를 따릅니다. 이것은 실험적으로 확인된 사실입니다. 따라서 정규분포에서 파생되는 분포들은 곧바로 실제 전자 시스템의 분석 도구가 됩니다.
01 카이제곱 분포   χ²(k) Chi-square

핵심 아이디어: 정규분포 변수들을 제곱하여 더한다.
서로 독립인 표준 정규분포 확률변수 k개를 각각 제곱한 뒤 합산하면, 그 합은 자유도(degree of freedom) k인 카이제곱 분포를 따릅니다.

카이제곱 분포의 유도
Z1, Z2, …, Zk  ~  N(0, 1)  (독립)
↓   각각 제곱한 뒤 합산
X = Z12 + Z22 + … + Zk2  ~  χ2(k)
k = 자유도 (더한 변수의 개수)  |  X ≥ 0 항상  |  E[X] = k, Var[X] = 2k
카이제곱 분포 PDF
f(x; k)  =  x(k/2)−1   e−x/2 2k/2   Γ(k/2)  ,   x > 0
Γ(·) = 감마 함수. k=1이면 양의 실수에서 단조 감소, k≥3이면 종 모양에 가까워짐

Z2
정규변수 1개 제곱
k = 2
Z₁² + Z₂²
= 지수분포 (특수 케이스)
k = n
Σ Zᵢ²
k → ∞이면 정규분포에 수렴
전자공학 직접 응용 예
응용 ①   ADC 양자화 잡음 전력 분석
Analog-to-Digital Converter — 디지털 시스템의 입력단
ADC가 아날로그 신호를 디지털로 변환할 때 생기는 양자화 오차 e는 정규분포 e ~ N(0, σ²)로 모델링됩니다.

n개의 독립 샘플에서 발생한 양자화 오차 전력의 합은:

Ptotal = e₁² + e₂² + ⋯ + eₙ²  =  σ² · χ²(n)
이 잡음 전력이 정확히 카이제곱 분포를 따르기 때문에, ADC 스펙에 명시된 SNR(신호 대 잡음비) 달성 여부를 통계적으로 검증할 수 있습니다. 즉, "이 ADC가 규격을 만족할 확률이 얼마인가?"에 직접 답합니다.
응용 ②   무선 수신기 에너지 검출(Energy Detection)
스펙트럼 센싱 · 인지 무선(Cognitive Radio)
"지금 이 주파수 대역에 신호가 있는가, 없는가?"를 판단하는 에너지 검출기는 수신 신호의 에너지를 다음과 같이 계산합니다:

T = Σᵢ xᵢ²  (xᵢ는 수신된 잡음 샘플)
신호 없을 때: T ~ σ² · χ²(2N)  (N = 샘플 수)
"T가 임계값 λ를 넘으면 신호 있음"으로 판단합니다. 이 임계값 λ는 카이제곱 분포의 분위수(quantile)에서 직접 계산됩니다. 오탐지 확률(false alarm rate)을 0.01로 맞추려면 χ²(2N)의 상위 1% 지점이 λ가 됩니다.
02 레일리 분포   Rayleigh(σ) Rayleigh

핵심 아이디어: 2개의 정규분포 성분으로 만든 2차원 벡터의 크기(amplitude).
서로 독립인 정규분포 확률변수 2개를 I축, Q축 성분으로 갖는 2D 벡터의 크기(= 원점으로부터의 거리)를 구하면 레일리 분포가 됩니다.

레일리 분포의 유도
XI ~ N(0, σ²),   XQ ~ N(0, σ²)   (독립)
↓   벡터 크기 (2D 거리)
R  =  √( XI2 + XQ2 )  ~  Rayleigh(σ)
R ≥ 0 항상  |  E[R] = σ√(π/2) ≈ 1.253σ  |  최빈값(mode) = σ (가장 많이 나타나는 크기)
레일리 분포 PDF
f(r; σ)  =  r σ2   exp (− r2 2σ2 )  ,   r ≥ 0
r = 0에서 0으로 시작, r = σ에서 최대값, 이후 단조 감소
I-Q 좌표에서의 기하학적 해석

무선통신에서 신호는 항상 I(동상) 성분과 Q(직교) 성분의 2D 복소 벡터로 표현됩니다. 채널을 통과하면서 추가되는 가우시안 잡음이 I, Q 각각에 독립적으로 더해지면, 수신 신호의 진폭(크기)은 정확히 레일리 분포를 따릅니다. 이것이 "레일리 페이딩(Rayleigh Fading)"의 수학적 정의입니다.

복소 신호   s = XI + j·XQ
신호 진폭   |s| = √(X2I + X2Q) ~ Rayleigh(σ)
전자공학 직접 응용 예
응용 ③   레일리 페이딩 채널 모델
4G LTE · 5G NR · Wi-Fi — 모바일 무선통신 핵심 모델
스마트폰이 기지국과 통신할 때, 신호는 건물·지형에 반사되어 수십 개의 경로로 동시에 도달합니다. 이 다중경로(multipath) 신호들이 합쳐진 수신 신호의 진폭이 레일리 분포를 따릅니다.

h = hI + j·hQ  (채널 계수, hᵢ ~ N(0, σ²))
|h| ~ Rayleigh(σ)  ← 수신 신호 진폭
통신 엔지니어는 이 분포를 이용해 "링크가 끊길 확률(outage probability)"을 계산하고 링크 마진을 설계합니다. 5G 기지국 배치 계획도 이 계산에 기반합니다.
응용 ④   OFDM 수신기의 부반송파 이득 분포
Wi-Fi · LTE · DVB-T — OFDM 기반 모든 디지털 통신 시스템
OFDM(직교 주파수 분할 다중화) 방식에서 각 부반송파(subcarrier)는 독립적인 페이딩 채널을 겪습니다. 각 부반송파의 채널 이득 크기가 레일리 분포를 따르기 때문에, 수신기는 어느 부반송파가 강한지 약한지를 이 분포로 예측합니다.

|H(fk)| ~ Rayleigh(σ)   (k번째 부반송파 채널 이득 크기)
이 분포를 알기 때문에 수신기는 채널 상태가 나쁜 부반송파를 피해 적응적 변조(adaptive modulation)를 수행할 수 있습니다. 지금 Wi-Fi가 자동으로 속도를 조절하는 것도 여기서 비롯됩니다.
03 두 분포의 관계 — 제곱 하나의 차이

카이제곱 분포와 레일리 분포는 별개의 분포처럼 보이지만, R을 제곱하면 χ²(2) 분포로 이어집니다. 핵심은 전력(Power) = 진폭(Amplitude)² 라는 물리적 관계입니다.

레일리 분포와 카이제곱 분포의 관계
R  ~  Rayleigh(σ)
↓   제곱 (전력으로 변환)
R2  =  XI2 + XQ2  ~  σ2  ·  χ2(2)  =  지수분포(Exponential)
자유도 2인 카이제곱 분포 = 지수분포 (k=2일 때 성립하는 특수한 관계)
→ 수신 신호 전력은 지수분포를 따른다 — 무선통신 BER 계산의 핵심 근거
N(0, σ²) × 2개
√(x² + y²) →
Rayleigh(σ)
수신 신호 진폭
제곱 →
σ² · χ²(2)
수신 신호 전력
=  
σ²·Exp(½)
= σ²·χ²(2)  (k=2 특수케이스)
진폭(Rayleigh) ←→ 전력(σ²·Exp(½) = σ²·χ²(2)) : 제곱과 제곱근으로 연결
왜 이 관계가 중요한가 — 무선통신 BER 계산
무선통신에서 비트 오류율(BER, Bit Error Rate)을 계산하려면 수신 SNR의 분포를 알아야 합니다.
수신 SNR = (신호 전력) / (잡음 전력) = R² / σ² n

R² ~ χ²(2) · σ² 이므로 SNR이 지수분포를 따름을 알 수 있고, 이로부터 레일리 페이딩 채널의 평균 BER을 닫힌 형태의 수식으로 구할 수 있습니다. 4G/5G 표준의 링크 버짓(link budget) 계산이 이 공식에서 출발합니다.

핵심 정리
  • 정규분포는 출발점. 전자회로의 열잡음과 측정 오차가 정규분포를 따른다.
  • 카이제곱 분포 χ²(k) = 정규변수 k개를 제곱하여 더한 것. 물리적으로는 전력(Power)에 해당한다. ADC 잡음 전력, 에너지 검출기에서 직접 사용된다.
  • 레일리 분포 Rayleigh(σ) = 독립 정규변수 2개(I, Q)로 만든 2D 벡터의 크기. 물리적으로는 신호 진폭(Amplitude)에 해당한다. 레일리 페이딩 채널, OFDM 시스템에서 직접 사용된다.
  • 두 분포의 연결 고리: 레일리 진폭을 제곱하면 χ²(2) = 지수분포. 이것이 무선통신 BER 계산과 링크 마진 설계의 수학적 기반이다.
  • 자유도 k는 더한 독립 정규성분의 수 = 안테나 수 · 경로 수 · 샘플 수 등으로 직관적으로 해석된다.
