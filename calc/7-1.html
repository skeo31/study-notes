시각화

직교좌표 표현

빔 패턴 \(B\)를 \(x, y\)로 표현하면 곡선이 복잡해지고 방향 정보가 직관적이지 않다.

→ 지향성을 한눈에 파악하기 어렵다

극좌표 표현

\(r = B(\theta)\) 로 표현하면 곡선의 모양 자체가 빔의 방향과 폭을 나타낸다.

→ 지향성이 즉각적으로 보인다

03 / 07
Physical Model

두 마이크 배열 모델

간격 \(d\), 음속 \(c = 343\) m/s, 파장 \(\lambda = c / f\)

// 경로차 (Path Difference)
\[ \Delta = d \cos\theta \]
// 위상차 (Phase Difference)
\[ \psi = \frac{2\pi d}{\lambda} \cos\theta \]
// 두 신호의 합 (Sum Beam)
\[ y(\theta) = e^{j\psi/2} + e^{-j\psi/2} = 2\cos\!\left(\frac{\psi}{2}\right) \]
// 정규화 빔 패턴
\[ B(\theta) = \left|\cos\!\left(\frac{\pi d}{\lambda}\cos\theta\right)\right| \]

* 조향(steering)을 적용하면 \(\cos\theta\) → \((\cos\theta - \cos\theta_0)\) 로 일반화된다.

Key Formula

지향성 빔 패턴 — 일반식

조향각 \(\theta_0\)으로 빔 방향을 제어할 때

// General Beam Pattern (Delay-and-Sum)
\[ B(\theta) \;=\; \left|\, \frac{\sin\!\left(\dfrac{\pi d}{\lambda}(\cos\theta - \cos\theta_0)\right)}{\dfrac{\pi d}{\lambda}(\cos\theta - \cos\theta_0)} \,\right| \;=\; \left|\,\operatorname{sinc}\!\left(\frac{d}{\lambda}(\cos\theta - \cos\theta_0)\right)\right| \]

07 / 07
Calculus Connection

극좌표 적분과의 연결

빔 패턴의 넓이 = 총 수음 에너지

// 극좌표 면적 적분
\[ A \;=\; \frac{1}{2}\int_0^{2\pi} \bigl[B(\theta)\bigr]^2\, d\theta \]
  • 면적이 작을수록 지향성이 높다
  • 케플러 제2법칙과 동일한 적분 형태
  • 배열의 "지향성 지수(DI)" 계산의 기초
// 지향성 지수 (Directivity Index)
\[ \mathrm{DI} \;=\; 10\log_{10}\!\left(\frac{4\pi}{\displaystyle\int_0^{2\pi}\!\!\int_0^{\pi} [B(\theta,\phi)]^2 \sin\theta\, d\theta\, d\phi}\right) \]

빔이 좁아질수록 DI가 높아진다.
이중 적분 → 이중극좌표계로 확장.
