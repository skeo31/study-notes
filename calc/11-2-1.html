비판정법 (Ratio Test) 증명
∑aₙ 에서 limn→∞|an+1/an| = L 일 때
경우 (i): L < 1 이면 ∑aₙ 은 절대수렴한다.
아이디어증명 전략

매 n마다 비 |an+1/an|은 똑같지 않다. 하지만 공비가 r인 등비급수와 비교하면 수렴 여부를 판단할 수 있다 (비교판정법).

limn→∞ |an+1 / an| = L < 1

L < r < 1 인 수 r을 하나 고른다. (예: r = (L+1)/2)

극한 정의N 이후 비가 r 아래에 갇힌다

극한이 L이므로, 어떤 정수 N이 존재해서 다음이 성립한다:

n ≥ N 이면 |an+1 / an| < r 즉, n ≥ N 이면 |an+1| < r |an|
왜 가능한가?　lim = L이고 L < r이므로, ε = r−L > 0으로 잡으면 극한 정의에 의해 충분히 큰 N 이후 |비 − L| < ε, 즉 비 < L+ε = r 이 보장된다.
유한 항 제거n = 1 ··· N 구간은 무시해도 된다

n = 1, 2, …, N 까지 |aₙ|의 합은 유한한 값이므로, 전체 급수의 수렴·발산에 영향을 주지 않는다.

∑aₙ 의 수렴·발산 ⟺ ∑n=N+1∞ aₙ 의 수렴·발산

따라서 이제부터 n = N+1, N+2, … 부분만 살피면 충분하다.

반복 대입등비수열로 각 항을 위에서 누른다

n ≥ N 에 |an+1| < r|aₙ| 을 차례로 적용하면:

|aN+1| < |aN|·r |aN+2| < |aN+1|·r < |aN|·r² |aN+3| < |aN+2|·r < |aN|·r³ |aN+4| < |aN+3|·r < |aN|·r⁴

일반화하면:

모든 k ≥ 1 에 대해　|aN+k| < |aN|·rk
✎ 수정 원래 쓰신 증명에서 비교 대상을 |aₙ|r, |aₙ|r², … 로 적으셨는데, 여기서 아래 첨자는 변하는 n이 아니라 고정된 기준점 N이어야 합니다. 즉 |aN|·rk 으로 쓰는 것이 정확합니다.
등비급수비교 대상 급수는 수렴한다

k = 1 부터 시작하는 비교 급수:

∑k=1∞ |aN|·rk = |aN|r + |aN|r² + |aN|r³ + ···

0 < r < 1 인 등비급수이므로:

∑k=1∞ |aN|·rk = |aN|·r / (1−r) < ∞
✎ 수정 원래 쓰신 증명에서 합을 |aₙ|/(1−r) 로 적으셨는데, k = 1 부터 시작하므로 첫째 항이 |aN|r 이고, 정확한 합은 |aN|·r / (1−r) 입니다. (k = 0 부터 시작할 때만 |aN|/(1−r) 이 맞습니다.)
비교판정법∑|aₙ| 수렴 → 절대수렴

단계 4의 부등식을 k = 1, 2, 3, … 에 대해 모두 더하면:

∑n=N+1∞ |aₙ| = ∑k=1∞ |aN+k| < ∑k=1∞ |aN|·rk < ∞

비교판정법에 의해 ∑n=N+1∞|aₙ| 이 수렴하고,
유한 개의 초기 항을 합쳐도 수렴하므로:

∴ ∑n=1∞ |aₙ| 수렴 → ∑n=1∞ aₙ 절대수렴
비교판정법:　0 ≤ bₙ ≤ cₙ 이고 ∑cₙ 이 수렴이면 ∑bₙ 도 수렴한다.
